## Brand rules (non-negotiable — from the official pack)
Tokens (all exist as CSS vars in styles.css): `--kohai-ai-indigo #1F4E8C` (ALL interactive work: CTAs, links, eyebrows, seals), `--kohai-kon #1B2A4E` (dark stages, headings), `--kohai-shironeri #F5F0E8` (silk canvas), `--surface-card #FBF8F2` (washi), `--kohai-sumi #2C2C2C` (body), `--kohai-sakura #F2A7B0` (blossoms ONLY, never buttons), `--kohai-matcha #7A9033` (success/"Popular"), `--kohai-sky-on-dark #9DB4EC` (secondary copy + pattern lines on stages), `--kohai-aka #CB4C49` (torii logo mark ONLY, never UI), `--kohai-kin #C2A24B` (ichimonji gold strips, `--ichimonji` gradient), `--surface-stage` (radial gradient for dark stages), `--border-line`, `--shadow-card`, `--shadow-plaque`, `--radius-sm 3px`, `--radius-md 6px`.
1. Ornament is trim, not wallpaper: textures 3–6% ambient, 8–11% on stage grounds, full strength only in seals and border bands. ONE focal crest per stage (large cropped kamon at 7–11% opacity as a poster mark).
2. Motifs carry meaning — kamon by meaning: Seigaiha=flow/how-it-works, Sakura=people/roster, Asanoha=structure/growth, Kikyō=craft/precision/the brief, Matsu=endurance/privacy, Igeta=foundations/pricing/integrations, Ōgi=conversation/meetings, Kikkō=results/analytics. Never random.
3. Sakura pink is decorative only. Indigo does the work.
4. Motion is weather, not fireworks (slow, loop-safe, off under prefers-reduced-motion).
5. Type: Shippori Mincho (serif) for headlines — never UI chrome. Zen Kaku Gothic New: 700 buttons/labels/names, 500 chips, 400 body. Wordmark always serif. Sentence case everywhere; UPPERCASE only for eyebrows (sans 700, .14em tracking, ai-indigo or sky-on-dark).
6. NO emoji anywhere. Where a competitor uses emoji (e.g. Perplexity's "👉" step lists, Sintra's "🙌"), substitute kamon crests or thin unicode strokes (→, ·).
7. No photography in the core pack — illustration is botanical line-work. For ad formats that REQUIRE photography/video (creator UGC, documentary story, scene ads), define a "photo treatment": indigo-graded (kon shadows, silk highlights), a stage-gradient scrim for type, seigaiha border band at the cut, logo lockup small in corner.
8. Max 2 background colors per ad: silk + indigo stage. Certificate frames (double line with concave notched corners) for proof/pricing plaques. Seigaiha border band marks every light↔dark boundary.
9. Voice: calm, editorial, declarative, short paired imperatives ("Hire AI employees. Get finished work."). Second person implied. No "we're excited". AI employees have human names (Alfred = meetings; use Hana, Matsuo, Kiku as stand-ins and FLAG them as placeholders).
10. Compliance: NO invented stats, prices, customer counts or testimonials. Use visible placeholders: `$X`, `[N] teams`, `[Customer name]`, `[Metric]`. Flag every placeholder with a subtle dotted underline + legend.

## Engineering constraints
- Single file; only external refs are the relative `kohai/…` paths above. No CDNs, no frameworks, no JS required except optional tiny vanilla JS for nav highlighting.
- Mockups built from HTML/CSS (not images). Use `aspect-ratio` containers with inner 1080-wide layouts scaled via `transform: scale(var(--s))` and `transform-origin: top left`, wrapper sized to the scaled box, so type sizes in the mockup are true ad pixels. Compute scale with CSS (e.g. container query units `cqw`) or a tiny ResizeObserver script.
- Page canvas itself is on-brand: silk background, kon headings, indigo eyebrows, seigaiha-border band between major sections, a stage-colored hero.
- Responsive: format cards stack on mobile; mockups stay legible.
- Keep total output under ~45k tokens: reuse CSS classes across formats rather than repeating inline styles. Do not inline SVG pattern data; use the mask classes / file paths.
