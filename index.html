01 / Ad foundations

A billboard. Not a web page.

One idea. One focal point. One next step. Scale the brand up; leave the interface density behind.

Start with the canvas.

All dimensions in export pixels

Dashed lines = live area. Keep a 60px minimum inset on every canvas. For 9:16, reserve the top 250px and bottom 340px for platform chrome. These are conservative template guides; check each live Meta and TikTok placement.

Minimums: 64px headline, 30px body / CTA, 24px auxiliary labels. Never shrink essential copy to fit. Rewrite it. Serif is for headlines and the wordmark, never UI chrome. Chips use sans 500; names and labels use sans 700 unless treated as a display headline.

Indigo grade · Silk highlights

When the format needs a camera

The core pack has no photography; illustration is botanical line-work. For creator, documentary, or filmed scene ads, source cleared footage and grade it to kon shadows + silk highlights. Add a stage-gradient scrim behind type, a seigaiha border band at the cut, and a small corner lockup. Do not simulate a customer or creator with a fabricated portrait. F1

Type-only quote card

Familiar category. Unfamiliar outcome.

4:5 · Prospecting
Controlled A/B · Same typography, CTA, color, and placement1080 × 1350

Source pattern

Lindy. Copy the immediate category analogy, giant type, and contrasting outcome—not a customer quote or competitor identity.

When to useCold prospecting; test the job-to-be-done hook.

DoHold every variable but the hook constant.

Don'tImply ChatGPT affiliation or present this as a testimonial.

Anatomy

  1. 96px serif hook: familiar anchor in kon, useful twist in ai-indigo.
  2. One quiet text CTA, identically positioned in A and B.
  3. 54px corner lockup beneath a hairline.

This source-faithful long-hook control exceeds the eight-word still guideline. Test a short bank headline against the winner; do not reduce type size.

F11

Video storyboard frame

Four beats. A calm handoff from problem to action.

9:16 · Explainer / Reel
Motion is weather, not fireworks. The storyboard is intentionally still.15s example · 4 × 1080 × 1920

Source pattern

Talking-head / explainer Reels. Borrow the familiar hook → problem → demonstration → end-card sequence. This is a format convention, not an attributed performance claim.

When to useProspecting or retargeting when a workflow is clearer in time than in a still.

DoDesign for sound-off viewing and keep the final action on screen for three seconds.

Don'tUse bouncing UI, strobing, spinning seals, or fake live results.

Anatomy / timing

  1. 0–2s / Hook. Big serif line; readable on the first frame.
  2. 2–6s / Problem. One caption and a restrained list of scattered inputs.
  3. 6–12s / Kōhai does it. Two task props arrive slowly; draft and review remain explicit.
  4. 12–15s / End card. Larger lockup, paired imperative, one CTA.

Talking-head variant: replace the problem stage with cleared creator footage using F7's grade, disclosure, and caption rules.

Kōhai adaptation / motion

Use 300–500ms dissolves. Props move 24–40px over 800–1200ms with gentle ease-out, never overshoot. Ambient loops run 8–12s and return seamlessly. Reduced-motion versions use static frames / cuts; this page disables decorative motion when requested.

04 / Production checklist

Ready is a review.
Not a feeling.

Run this pre-flight for every ratio and every variant. Checkboxes are a local working aid, not an approval record.

For designers + generators

The handoff contract.

Build an ad, not a screenshot of this reference page. Use the actual brand assets and native export dimensions.

1. Choose
Lane → funnel stage → format → ratio.
2. Populate
Approved hook → support → prop → CTA → destination.
3. Constrain
Slot limits, safe area, two surfaces, one meaningful focal crest.
4. Verify
Claims, names, numbers, footage rights, and offer terms.
5. Export
Remove reference layers. Keep the final review visible in the delivery record.
